#  Forecasting" by Junyi Ye and Gargi Vijay Borde (2026). This manifest fixes the
#  complete transitive dependency closure so that a 30-seed replication executed
#  on any host reproduces the study's reported metrics bit-for-bit, and so that

#  Reproducibility Contract:
#  • Every distribution in the closure is pinned with '==' (28 packages total)
#  • No '>=' or '~=' operators: resolver drift would break paired-seed comparison
#  • Import-name-to-distribution-name mappings resolved explicitly (sklearn ->
#    scikit-learn) to prevent installation of deprecation-stub packages
#  • Standard-library modules (re, hashlib, inspect, itertools, json, logging,
#    math, random, sys, dataclasses, datetime, importlib.metadata, pathlib,
#    typing, __future__) are deliberately absent: pinning them is a hazard
#  • Optional acquisition dependencies are isolated so that the modelling and
#    evaluation stack installs and runs in fully air-gapped environments
#
#  Verified Reference Environment:

# numpy — panel arrays, rolling-window kernels, RNG (default_rng) for the
# 30-seed registry, and the dtype substrate for every torch tensor bridge.
# HARD FLOOR AT 2.x: legacy aliases np.float_, np.NaN, np.int0 were removed in
# NumPy 2.0. Reproduction code authored against 1.26 fails at import, not at
# runtime — treat any AttributeError on these names as a wrong-pin diagnostic.
numpy==2.4.6

# scipy — supplies four distinct study-critical kernels:
#   optimize.minimize -> per-stock GARCH(1,1) MLE under positivity/stationarity
#   stats.spearmanr   -> daily cross-sectional information coefficient
#   stats.t           -> Student-t residual fit for 5% / 1% VaR thresholds
#   stats.chi2        -> chi-square(1) null for Kupiec unconditional coverage
# Patch-level pin is mandatory: SciPy has altered spearmanr tie-handling and
# t.fit optimizer defaults within minor series, which shifts IC and VaR results.
scipy==1.18.0

# pandas — panel alignment across ~1,500 US and 1,552 TSE Prime tickers on a
# reconciled trading calendar; all rolling realized-volatility, beta, RSI, and
# forward-target construction.
# BREAKING-CHANGE ADVISORY (pandas 3.0): Copy-on-Write is permanently enabled
# and can no longer be disabled; 'pd.options.mode.copy_on_write' now emits
# Pandas4Warning. Chained assignment of the form df[col][mask] = value is a
# SILENT NO-OP under CoW. Every rolling-feature write must use .loc/.iloc
# single-step indexing or an explicit .assign(). This is a correctness hazard
# for look-ahead auditing, not a style preference.
pandas==3.0.3

#     pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
